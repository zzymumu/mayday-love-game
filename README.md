# 那年夏天，還有未讀訊息

五月天同人戀愛互動遊戲。故事從 **1996 年**的台灣大學校園生活開始，描寫樂團尚未成名時的青春日常，時間一路推進至 **1999 年五月天發行第一張專輯**，並以此作為主線終點與最終結局結算節點。角色互動及戀愛劇情均為架空同人創作。

## 核心故事設定

- 女主固定為台灣大學社會學系學生，只有姓名可以由玩家自訂。
- 故事時間跨度：1996—1999 年。
- 可攻略角色：瑪莎、溫尚翊、陳信宏、石錦航、劉諺明。
- 五位角色各自累積獨立好感度與劇情旗標，玩家可自由選擇聯絡對象。
- 1999 年第一張專輯發行事件是主線終點，屆時根據各角色好感度、關鍵劇情旗標及玩家最終選擇結算 HE／OE／BE；若沒有任何角色達成條件，也可以進入單身結局。
- 線下面對面、校園、排練室與約會劇情一律使用第二人稱「你」的沉浸式旁白；女主手機中的私人日記使用第一人稱「我」。
- 手機訊息、通話與日記共同呈現故事；重要選擇由玩家親自決定，不自動替玩家回覆。

## GitHub Pages

此專案使用 GitHub Actions 自動部署。工作流程位於 `.github/workflows/deploy.yml`，每次推送到 `main` 都會建置並發布 `dist`。

請在 GitHub repository 的 **Settings → Pages → Build and deployment** 中，將 **Source** 設為 **GitHub Actions**。

## 目前可遊玩內容

第一章開場已加入可操作流程：溫尚翊的簡訊通知、過去數週的歷史簡訊、三個不同好感度的回覆、台大校園同行旁白、練團室成員逐一介紹，以及與瑪莎的意外重逢。玩家選擇與劇情進度會保存在目前瀏覽器的本機儲存空間。

目前劇情暫停於溫尚翊問出「妳們認識喔？」的時刻；瑪莎的單獨談話、回家後日記與完整通訊錄解鎖會在後續章節更新。其他 App 仍是逐步開發中的入口畫面。

玩家姓名目前儲存在瀏覽器本機；清除瀏覽器資料或更換裝置不會自動同步。
